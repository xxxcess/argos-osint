# Shared React packages

Follow root [AGENTS.md](../AGENTS.md), the [agent workflow](../docs/wiki/code/agent-workflow.md) ([scope and finish line](../docs/wiki/code/agent-workflow.md#scope-and-finish-line)), [React UI rules](../docs/wiki/code/react-ui.md), [Glass Canvas theme](../docs/design/matte-canvas/theme.md), and [interaction-state contract](../docs/design/matte-canvas/interaction-state.md).

- **Ownership & skills:** Load `argos-react-ui` for visual/interaction work and `argos-react-patterns` for components, hooks, state, or performance. `ui` owns shared tokens/primitives; `intel` owns screens; `api-client` owns Query/connection state; browser persistence/UUIDs belong in app adapters.
- **Composition & topology:** Apply shared Glass Canvas paint and loading/continuous-scroll targets within existing web routes (native mockups do not add Intel destinations or prove runtime behavior). Topology in `intel` uses `ForceCanvas` (`react-force-graph-3d`) plus its accessible list twin; keep mutable engine data outside Query state.
- **Compiler & state:** Use React Native primitives with React Compiler/Hooks diagnostics enabled (pure renders, unconditional hooks, complete deps; fix diagnostics rather than suppressing). Preserve opaque cursors and distinguish loading, verified empty collections, and numeric zero.
- **CI & hygiene:** In Nightly GSD, run affected checks/builds in [GitHub Actions](../.agents/skills/gsd/SKILL.md#github-ci-first) per [CI contracts](../docs/wiki/code/ci.md) and `.github/workflows/intel-web.yml`. Follow [build cache hygiene](../docs/wiki/code/contributing.md#build-cache-hygiene). Do not run Rust mutation tests (`cargo mutants`) locally; use hosted `mutation.yml` and report local mutation as skipped.
