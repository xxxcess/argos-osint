## Cross-cutting wire contract

Every row records the resource target independently from registered request origin. Five Backend pages use permitted shared data/configuration. Interactive durable submissions require validated current registration, expected context revision, operation-scoped request ID, immutable non-secret configuration/credential references and durable origin/request association. Global settings save with expected configuration revision. Registration/session revisions are independent.

All Jobs/log links resolve server membership for the scoped workstation before pagination/count/details/export/live. Shared association grants only permitted status/events, not another creator's private input or cancellation rights. Legacy/system rows do not acquire invented provenance. Transport cancellation is not durable job cancellation.
