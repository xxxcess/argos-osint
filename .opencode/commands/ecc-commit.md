---
description: Prepare or create a scoped Conventional Commit for authorized Argos work
---

Use the argos-commit skill for $ARGUMENTS. Follow docs/versioning.md. On plan, prepare a message and release-impact assessment without staging or committing. On build, complete the authorized commit task with exact staging, policy checks and a descriptive message; preserve unrelated changes and report the commit SHA. This command does not authorize pushing, merging or publishing a release.
