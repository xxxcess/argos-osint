Local CLI and TUI development loop

Venture and the six fleetworks-* terminal clients build and test directly on the host. Running a client against an active stack exercises real HTTP routes without rebuilding any Docker image.

When stdin and stdout are terminals, tui opens the Ratatui screen (list + detail panes, modal confirmation with explicit y). Piped stdio keeps the line-oriented session for scripts and integration tests.
