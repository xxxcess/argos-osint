Intel Web: existing-ID gate and current context

The server validates a current registry-backed session at every protected entry. Browser state can describe the selected context but cannot supply backend authority. The Connect form is the narrow public path into this boundary; topology and its accessible list remain web-owned.

Source: central session guard, custom server boundary, server API relay, bounded live relay and registry/session routes. Protected static exceptions contain only the Connect surface and required assets, not application data.
