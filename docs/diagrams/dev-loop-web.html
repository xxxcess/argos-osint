Web development container and browser loop

In development mode, Next.js runs inside the web_dev container over read-only bind mounts of the host app and package sources. Browser verification uses isolated output so the user's running frontend lock is untouched.

Setting ARGOS_WEB_TEST_DEV=1 redirects test builds andlocks to .agent-scratch/next-web-tests, preserving the developer's active .next directory.
