Fleetworks service boundaries

Venture owns the local stack. Terminal clients and the Intel web relay use the authenticated API. The gateway relays retained operations to private Brain. The optional Atlas worker reads the transactional outbox, dispatches through RabbitMQ and calls the private NLP and classifier services.

The figure shows the managed disk profile. The workspace can also use a host or external SurrealDB server. The base stack includes schema bootstrap and a background worker.
