---
name: ecc-checkpoint
description: Create a concise manual handoff for Argos work.
---

Follow the canonical [scope and finish-line policy](../../../docs/wiki/code/agent-workflow.md#scope-and-finish-line) and the active host’s permissions; OpenCode roles apply only when selected.

Return under 200 words: latest request, achieved outcome, remaining acceptance, changed paths, actual checks, blockers and one next action. Include active process/log ownership and commit/release impact only when relevant.

Keep runtime IDs local and follow [planning retention](../../../docs/wiki/code/planning-artifacts.md). A checkpoint is a handoff, not a new audit or task. Explicitly wake completed agents only when authorized follow-up remains; honor wrap-up immediately.
