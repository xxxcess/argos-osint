External Venture operator lifecycle

Venture remains a supported external operator tool. Explicit operator commands select a deployment workspace and storage target, start or reconcile owned services, check readiness and optionally attach the retained operator CLI. This is separate from native application startup, gateway profiles and local origin children.

Source: Venture command routing and owned deployment lifecycle. Native startup belongs in Native connections; no native view starts Venture, Docker, a server or the web stack. Exiting an operator session preserves the deployment. Stopping it remains an explicit operator action and retains persistent data.
