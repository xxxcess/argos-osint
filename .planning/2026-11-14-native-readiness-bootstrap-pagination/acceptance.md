The user directed this session to use GitHub CI for builds and tests, with local compilation only when native review is needed. The passing ARM artifact triggered that review while broader gates continued. Native review checks the pinned size and SHA-256 of the materialized Git LFS actor dataset before Docker build or service stop, mounts it read-only, and sets `FLEETWORKS_BOOTSTRAP_ACTOR_CSV`; bootstrap checks the same fingerprint before ingestion. Generic bootstrap without that variable initializes storage without actor seeding. The runtime image does not bundle the dataset. Cycle, job and log pages use bounded cursor contracts. The old `native-local` SurrealDB container reports write failures because its bind-mounted host data path is missing; it was left untouched. The new review stack uses a separate intact data path and remained healthy.
