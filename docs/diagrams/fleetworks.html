Native clients, independent backend

The macOS app owns local identity and calls the gateway. Intel Web has its own server session gate and keeps topology. An operator provisions services independently; neither client starts them. Shared backend resources remain separate from immutable workstation/workspace request origin.

This depicts the implemented source boundaries. Durable reindex integration, installed dual-Mac parity, publication and retirement have separate verification gates; a diagram is not release evidence. SurrealDB retains scheduling and domain fences while Jobs exclusively opens operational SQLite and the embedded queue.
