# Argos React patterns

Follow the [agent workflow](../../../docs/wiki/code/agent-workflow.md), `docs/wiki/code/react-ui.md` (ownership/design), `docs/wiki/code/intel-web.md` (client contracts), and installed Next docs via `apps/web-desktop/AGENTS.md` before changing app APIs. Load `argos-react-ui` for visual/interaction work.

- **Primitives & boundaries:** Use React Native primitives, `StyleSheet.create`, and `@argos/ui`. Keep DOM/browser APIs in app code or explicit web adapters (persistence/UUIDs via `BackendSettings`). Keep server/client snapshots hydration-safe—never initialize persisted state with a synchronous `setState` effect.
- **Rendering & composition:** Wrap text in `Text`; guard `0`/`""` with boolean checks or null-returning ternaries. Key lists by stable data identity (run/article occurrences), not array indexes when reorderable. Prefer slots/children and explicit variants over boolean prop proliferation; add compound context only when parts genuinely share state.
- **State & TanStack Query:** Query in `@argos/api-client` owns remote data, pagination, and mutations (never SWR or ad-hoc fetch effects); Context owns backend/preferences/connectivity; component state owns local UI. Derive display values in render instead of mirroring fetched data in effects/state; trigger mutations from event handlers (except documented once-per-occurrence brief admission).
- **Async & continuous scroll:** Distinguish pending, refreshing, next-page, error, and verified empty states; retain readable data during refresh and preserve numeric `0`. Preserve query namespaces, `enabled`/readiness gates, opaque cursors, cache invalidation, and parallel independent reads. Continuous scroll must guard in-flight loads, isolate keys, deduplicate occurrences, keep stable viewport anchors, and keep continuation/retry reachable without routine Previous/Next/page-number chrome (`docs/design/matte-canvas/interaction-state.md`).
- **React Compiler & perf:** Keep React Compiler enabled across Next and transpiled packages; `pnpm lint` fails on Hooks/Compiler warnings—keep renders pure, hooks unconditional, props/state immutable, refs outside render, and effect deps complete. Fix diagnostics rather than suppressing or adding blanket `use no memo`. Scope subscriptions tightly; let the compiler handle routine memoization and measure before adding manual memo/`useCallback`/virtualization (preserve existing intentional memo contracts; inline dynamic styles are fine).
- **Bundles & topology:** Keep imports statically analyzable; lazy-load heavy optional features only with bundle evidence, keeping static-export compatibility and fallbacks. Avoid incidental server actions, API routes, native navigation, or Expo image/animation deps. Compiler/dependency changes require compatible pins plus both export and dev browser checks (`ARGOS_WEB_PROFILE=dev pnpm test:e2e`). Topology uses `ForceCanvas` (`react-force-graph-3d`) lazily client-only with tokens passed to draw code, reduced-motion support, and its accessible list twin (`react-ui.md#canvas-visualizations`)—no second graph renderer.
