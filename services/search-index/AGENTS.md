# Private actor search service

Read [root guidance](../../AGENTS.md), [contributing](../../docs/wiki/code/contributing.md), [conventions](../../docs/wiki/code/conventions.md), and `argos-rust-style` before edits. The integration owner controls manifests/lock/toolchain and the shared agent Cargo cache; preserve unrelated work and index evidence.

- **Boundary:** Private Linux backend engine only—keep Tantivy out of desktop, shared client DTOs, inference, and unrelated graphs. No DB replacement, Docker supervisor, arbitrary command/URL/path endpoints, or public admin API.
- **Projection & fences:** SurrealDB actor/alias/lifecycle records are truth. Producers write outbox intent atomically; only the leased, authenticated coordinator sends bounded batches and acks reader-visible receipts. Preserve source/deployment/schema/analyzer/index-format/generation/revision, tombstone, and coordinator-epoch fences in one Tantivy commit; equal revision with different content must fail.
- **Locking & recovery:** One process/root lock and active writer budget—never delete lock files, auto-delete, or silently repair indexes. Shadow replacement keeps the last verified reader until promotion.
- **Bounds & runtime:** Enforce count/byte/rate/concurrency limits upfront (no unbounded queues, per-actor HTTP fan-out, user query-parser/regex, or full-catalog memory loads). Keep blocking search/write/commit work off Tokio and hold capacity permits across uncertain timeouts; coordinator owns retries/pacing.
- **Auth & testing:** Hits are candidates—gateway authorizes canonical actors and fetches dossiers separately (scores rank retrieval only, never confidence). In Nightly GSD, run checks/image builds in [GitHub Actions](../../.agents/skills/gsd/SKILL.md#github-ci-first). Use synthetic data and temp roots (no live providers, user homes/volumes, or local mutation runs), keep real recovery evidence distinct from mocks/PNGs, and keep README limitations honest.
