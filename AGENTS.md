# Argos OSINT — Agent orientation

Fleetworks uses Venture to run network services, native terminal clients, and the React Native Web desktop. Legacy Argos CLI/TUI and embedded SurrealDB are still present during the cutover.

- Start at [docs/index.md](docs/index.md), then the [Fleetworks guide](docs/wiki/code/fleetworks.md) or the relevant legacy concept/code route. Read [contributing](docs/wiki/code/contributing.md) and [conventions](docs/wiki/code/conventions.md) before edits/checks. Preserve unrelated work; `.github` changes belong to Code Architect.
- Follow [scope and finish-line rules](docs/wiki/code/agent-workflow.md#scope-and-finish-line): pin the requested outcome, non-goals and acceptance; review risks early; freeze before final checks. Defer unrelated findings. Late fixes require a demonstrated in-scope blocker and an affected check, not another broad audit. Honor wrap-up immediately.
- Use subagents early when independent work shortens delivery. Assign disjoint paths and concrete outcomes; keep one integration/build owner, wake idle workers explicitly and reuse unaffected evidence. See [execution policy](docs/wiki/code/agent-workflow.md).
- Ask once for verification scope unless already authorized. Read [testing guidance](.opencode/skills/argos-testing/SKILL.md) before tests. Report failures, skips and unverified work honestly; no extra approval gates within existing authorization.
- Rust builds use `python3 scripts/agent_cargo.py … --locked` and the shared `target/agents` cache. Use the scoped Fleetworks checks for the network clients and services. Run the native embedded gate for affected legacy runtime and embedded-storage paths. Server/all-platform matrices and Rust mutation tests run in hosted CI. Follow [CI](docs/wiki/code/ci.md) and [cache hygiene](docs/wiki/code/contributing.md#build-cache-hygiene); protect `target/debug`, active builds and global caches.
- Multi-phase work uses a concise [named plan](docs/wiki/code/planning-artifacts.md#working-format); separate implementation from verification. Scratch belongs in `.agent-scratch/`, unstaged.
- Update only affected docs/tags/contracts/diagram pairs in the same change. Trace cross-cutting concerns with [tags](docs/wiki/tags.md); follow [wiki maintenance](docs/wiki/maintenance.md).
- Rust changes load `argos-rust-style`; Argos async rules/layout override conflicting upstream platform rules. `cargo fmt` remains the formatter.
- React work loads `argos-react-ui` and, for components/state/performance, `argos-react-patterns`. Follow [React rules/theme](docs/wiki/code/react-ui.md): terminal desk plus HUD/glass, shared primitives/tokens, Compiler/Hooks lint, affected fixture screenshots. Topology uses `ForceCanvas` and its list twin.
- Browser verification uses repository Playwright. Set `ARGOS_WEB_TEST_DEV=1` for isolated test output/locks under `.agent-scratch/next-web-tests`; preserve the user's frontend and `.next` locks.
- TUI changes load `argos-tui-verify`; follow [design](docs/wiki/code/tui-design-spec.md), [components](docs/wiki/code/tui-components.md), [verification](docs/wiki/code/tui-verification.md), and [Profile analytics](docs/wiki/code/profile-analytics-dashboard.md) when affected. Keep thin borders, ACCENT focus and SELECT selection; inspect captured PNGs.
- Host-specific roles apply only when selected: [OpenCode](.opencode/AGENTS.md), [workflow](docs/wiki/code/opencode-v2.md), [Antigravity](.agy/howto.md) ([lite](.agy/lite-team.md), [heavy](.agy/heavy-team.md)).
