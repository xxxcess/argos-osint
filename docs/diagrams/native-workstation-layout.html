Native workstation shell and settings composition

On wide windows, the native app pairs a compact operations sidebar with the selected destination and a read-only context rail. The toolbar holds the command button, the Inbox tray with an unread badge and the Assistant toggle. The Assistant is off by default; when on, it docks where the rail is, with a pinned context, a history and a glass composer. The Inbox drawer opens over the right edge and preserves the selected destination and Assistant. Jobs and Logs shows a paged list beside the selected job. Settings opens a centered category-and-content dialog. Narrow windows keep the selected destination and hide the right panel. This diagram is not installed-app verification.
