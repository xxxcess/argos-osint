Native workstation shell and settings composition

The native shell pairs a compact operations sidebar with the selected destination. On wide operations pages it can show a read-only context rail. The toolbar holds telemetry, the Inbox bell and the optional Assistant toggle. Select the brand avatar to open Workstation Status. The Assistant is off by default; when on, it docks where the rail is, with a pinned context, a history and a glass composer. The Inbox popover opens below the toolbar bell and preserves the selected destination and Assistant. Jobs and Logs groups the jobs by status. Selecting a job slides into its details and logs. Settings opens a centered category-and-content dialog. Narrow windows keep the selected destination and hide the right panel. Installed-app evidence is tracked in native verification.
